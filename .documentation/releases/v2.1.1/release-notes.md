## Highlights

This patch release focuses on documentation quality gates and frontend maintainability improvements identified during release audit.

The site-audit workflow now enforces generated-artifact exclusions from configuration, preventing false positives during security pattern checks. This aligns release auditing with Constitution Principle VI and keeps findings focused on maintained source trees.

The repository drill-down modal was refactored into focused hooks, utilities, and section components. The main container component was reduced from 1261 lines to 174 lines, addressing the single-responsibility concern from the prior audit.
